HOW ROGUELIKE RUNS WORK

Route the lane, beat frame targets, survive bosses, build a house style.

1 // Pick A Lane

Each run is 12 frames. Choose a route before each frame. Riskier lanes pay more pin dollars and change the rack.

2 // Beat The Target

Knock down enough scoring pins within your rolls. Special pins, gold pins, messy layouts, and boss rules change what “good” looks like.

3 // Shop And Reroll

Spend pin dollars between frames. Bought cards stay sold out until you reroll, and rerolls get pricier each shop visit.

4 // Boss Frames

Frames 4, 8, and 12 are boss lanes. They announce their rule changes before you bowl so the drama is readable.

5 // Relics

Relics are meta upgrades selected before a run. They bend the entire run, like a one-time extra chance when you would bust out.

6 // Saves

Choose a run slot before starting. Roguelike runs autosave to that slot at route, shop, and upgrade breaks.
